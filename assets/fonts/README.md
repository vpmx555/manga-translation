# Font dàn chữ v6

Font mặc định: `astro-city-teddy-bear.ttf`, bản sao của font người dùng cung cấp
`000 AstroCity [TeddyBear].ttf`. `v6.font_path` dùng đường dẫn tương đối từ gốc
repository; có thể ghi đè bằng đường dẫn tuyệt đối tới một font khác.

Font được resolve và ghi SHA-256 vào kế hoạch dàn chữ. Nếu font được cấu hình
không tồn tại, pipeline báo lỗi để tránh âm thầm thay font.
